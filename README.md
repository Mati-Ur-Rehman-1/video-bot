# AI Video Generator 🎬

A web-based AI video generator capable of transforming text prompts into stunning videos.  

-  **Video Generation:** Create cinematic videos from descriptive prompts  
-  **Custom Duration & Quality:** Choose video length and resolution (480p, 720p, 1080p)  
-  **Preview & Download:** Watch and download generated videos  

The frontend is built with **HTML/CSS/JS**, and the backend interacts with an AI video generation API. The project can be deployed on **Azure Web App Service**.

---

## **Features**

1. **Video Generation**
   - Generate videos from descriptive text prompts
   - Set video duration (5–20 seconds)
   - Choose video quality (480p, 720p, 1080p)

2. **Progress Tracking**
   - Real-time generation progress bar
   - Status indicator: Ready, Processing, Failed

3. **Video Download**
   - Download generated video to your device
   - Option to create a new video after download


---

## **Tech Stack**

- **Frontend:** HTML, CSS, JavaScript  
- **AI Models / APIs:** Custom or third-party AI video generation API  
- **Hosting/Deployment:** Azure Web App Service
